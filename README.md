# Task 1 - Iris Flower Classification

## Objective
Develop a machine learning model that classifies Iris flowers
into Setosa, Versicolor, and Virginica species based on their
sepal and petal measurements.

## Dataset
The Iris dataset contains measurements of:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Algorithm Used
Decision Tree Classifier

## Steps
1. Load the Iris dataset
2. Split the dataset into training and testing data
3. Train the Decision Tree model
4. Make predictions
5. Evaluate model accuracy
6. Generate a confusion matrix
7. Predict the species of a new Iris flower

## Result
The model successfully classifies Iris flowers into their
respective species.
